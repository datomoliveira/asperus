# Motion Design Skill — Character & Web Motion Guide

## Core Principles

1. **Easing & Anticipation**:
   - Use custom cubic-bezier easing (`power2.out`, `elastic.out(1, 0.4)`, `back.out(1.7)`) to convey physical weight and momentum.
   - Character animations (e.g., 3D avatars) should feature subtle breath, head tilts, and micro-movements to feel alive rather than static.

2. **Follow-Through & Secondary Action**:
   - Accessories on characters (such as caps, chains, clothing elements) should follow the primary torso movement with slight delay and springiness.

3. **Spatial Interaction**:
   - Interactive elements respond to user cursor proximity with proportional tilt, scale shifts, and ambient lighting changes.
