03 / Projetos

Trabalho que ficou de pé.

Quatro peças. Contexto real, decisões reais. Abra a costura de cada uma.

Plataforma de operações que substituiu sete planilhas e centralizou o fluxo de uma operação inteira.

Contexto

Dados espalhados, retrabalho e nenhuma fonte de verdade. O time sabia o que precisava — faltava uma peça que costurasse tudo.

Decisão

Modelo de dados único, permissões por papel e uma interface que abre no navegador sem manual.

Resultado

Uma operação inteira em um só lugar. Menos planilha, menos ruído, mais decisão.

React · Node.js · PostgreSQL · Redis

Analytics em tempo real para times não técnicos acompanharem o que importa sem depender de SQL.

Contexto

Relatórios manuais, números desatualizados e decisões tomadas no escuro.

Decisão

Pipeline de eventos, cache agressivo e visualizações desenhadas para leitura rápida — não para exibir gráficos.

Resultado

O time passou a olhar para o mesmo número, no mesmo instante, sem pedir extrato para ninguém.

Next.js · TypeScript · AWS · WebSockets

Gateway que normaliza autenticação, rate limit e observabilidade para múltiplos serviços.

Contexto

Cada serviço resolvia autenticação do seu jeito. O resultado era inconsistência, ruído e apagação de incêndio.

Decisão

Uma camada fina em Go, contrato explícito e métricas no mesmo lugar. O resto virou consequência.

Resultado

Menos duplicação, diagnóstico mais rápido e um caminho claro para novos serviços.

Go · Cloudflare · Microservices · OpenTelemetry

Commerce mobile-first com checkout e catálogo pensados para conexões ruins e telas pequenas.

Contexto

O funil perdia gente no meio do caminho. A experiência tinha sido desenhada para desktop e adaptada no grito.

Decisão

Começar pelo celular, cortar passos do checkout e tratar conexão instável como requisito, não como exceção.

Resultado

Um fluxo curto, legível e resiliente. A compra deixou de ser um teste de paciência.
